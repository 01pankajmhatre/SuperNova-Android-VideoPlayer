# SuperNova Android Video Player

SuperNova is an independently developed Android video player based on the open-source NOVA Video Player project.

## Original Projects and Acknowledgements

This project builds upon:

- NOVA Video Player: https://github.com/nova-video-player/aos-AVP
- Archos Video Player Community Edition: https://github.com/archos-sa/aos-AVP

## Modifications

SuperNova includes additional modifications, features, improvements and customizations developed independently.
